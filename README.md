# CPTS484-Project-THEIA

Project THEIA is a smartphone application designed to assist blind and visually impaired individuals with indoor navigation. This project is developed for the CPTS 484 course at Washington State University (WSU).

## Team Members
- Vijay Deva
- Julia Smith

## Project Overview
THEIA guides users from one indoor location to another across connected buildings. The application relies on voice commands, real time audio instructions, and haptic feedback instead of screen readability. It prioritizes safe and fast navigation by integrating obstacle detection and automated emergency response features.

## Core Features
- Initial Room Wayfinding: Voice command input and tactile menus for selecting frequent destinations.   
- Precise Indoor Turn Navigation: Real time step distance cues and accurate turn timing.   
- Hazard and Obstacle Avoidance: Floor level obstacle detection and maintenance rerouting.   
- Automated Emergency Response: Fall detection and automated distress messaging to designated contacts.   
- Low Vision Accessibility: High contrast visual interface with scalable text and clear directional arrows.
